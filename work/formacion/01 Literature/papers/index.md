## Incorporar nuevos papers

Para añadir un paper:

1. Añadir entrada a [`bibliography.bib`](bibliography.bib)
2. Crear nota Markdown con: resumen, hallazgos clave, conexión con qlib, tags
3. Enlazar la nota desde este índice
