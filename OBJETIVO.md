# OBJETIVOS DEL PROYECTO

Este proyecto, tiene un objetivo declarado: tener una cartera de renta variable US con riesgo controlado, medida honestamente, y aprender a hacerlo bien. Eso es alcanzable con lo que tienes y no depende de encontrar un edge que probablemente no existe.

Y efectivamente, el objetivo es ganar dinero batiendo al mercado, vamos a indexarnos y usar el proyecto para aprender, no para generar rentabilidad.
